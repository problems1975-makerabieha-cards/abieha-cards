تشغيل لعبة أبيها أونلاين

1) ثبّت المكتبات:
pip3 install -r requirements.txt

2) شغّل السيرفر:
python app.py

3) افتح الرابط:
http://127.0.0.1:5000

4) من أكثر من جهاز:
ادخل نفس كود الغرفة مثل ROOM1

ملاحظة:
هذه نسخة أونلاين محلية/سيرفر. للرفع على الإنترنت استخدم استضافة تدعم WebSocket مثل Render أو PythonAnywhere مع SocketIO.
